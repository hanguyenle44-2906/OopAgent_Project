# Error Recovery

Khi 1 tool tra ve ket qua bat dau bang "Loi:", ap dung quy tac sau:

1. DOC KY thong bao loi de hieu nguyen nhan that su (vi du: sai tham so,
   file khong ton tai, chia cho 0), khong doan mo ho.
2. KHONG goi lai tool voi CHINH XAC cung tham so da that bai - dieu nay se
   bi Loop Detector coi la vong lap va chan lai.
3. Sua tham so dua tren thong bao loi cu the (vi du: sai duong dan file thi
   thu duong dan khac hoac dung tool file de kiem tra thu muc truoc).
4. Neu da thu toi da 2 cach khac nhau ma van that bai, bao cao ro rang cho
   nguoi dung biet task khong the hoan thanh va ly do, thay vi tiep tuc thu
   vo han lan.
